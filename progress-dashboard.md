## 💡 **NOTAS Y DECISIONES TÉCNICAS**

### **Decisiones de Arquitectura:**
- **Stack:** HTML5 + CSS3 + Vanilla JS (frontend) + Python Flask (backend)
- **Estado:** LocalStorage para persistencia cliente
- **API:** Flask REST con MongoDB
- **Responsive:** Mobile-first approach
- **Performance:** Lazy loading, código minificado

### **Sistema de Componentes Implementado:**
```css
/* Sistema de Botones */
.btn--primary { background: var(--color-primary); }
.btn--lg { height: var(--button-height-lg); }
.btn--loading::after { /* spinner animation */ }

/* Formularios */
.form-input:focus { border-color: var(--color-primary); }
.form-error::before { content: '⚠️'; }

/* Cards Interactivas */
.card:hover { transform: translateY(-2px); }
.card--interactive:hover { transform: translateY(-4px); }

/* Modals Responsive */
.modal { transform: translate(-50%, -50%) scale(0.9); }
.modal.active { transform: translate(-50%, -50%) scale(1); }
```

- **Buttons:** 7 variantes (primary, secondary, outline, ghost, success, warning, danger)
- **Forms:** Complete form system con validación visual y estados de error
- **Cards:** Interactivas con hover effects y estructura header/body/footer
- **Loading:** Spinner, skeleton loading, full-screen overlay con fade
- **Alerts:** 4 tipos semánticos con iconos y colores automáticos

- **Performance:** Efficient animations, reduced motion support
